# Image dataset: Car Insurance Fraud Detection

Source: https://www.kaggle.com/datasets/pacificrm/car-insurance-fraud-detection

How to set it up:

1. Download the dataset from Kaggle and unzip it anywhere on your computer.
2. Find the folder that contains `train/` and `test/`. Each of those has `Fraud/` and `Non-Fraud/` folders inside.
3. Open the notebooks and change `DATA_DIR` in the first cell to that folder's path.

Expected counts:
- train: 200 Fraud, 5,000 Non-Fraud
- test: 93 Fraud, 1,323 Non-Fraud
